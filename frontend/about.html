HOW AN ANSWER IS BUILT

One question. Five accountable layers.

The model explains evidence; it does not replace the evidence.

  1. 01
    Understand place and intent“My area” uses consented GPS. A named village, city, district or state overrides it.
  2. 02
    Resolve official contextThe coordinates are linked transparently to the nearest indexed GWRA assessment unit.
  3. 03
    Assemble evidenceBlock category, state recharge and extraction, water quality, depth trends and live weather are gathered.
  4. 04
    Generate in your languageA configurable language model receives only the relevant structured evidence and conversation context.
  5. 05
    Show the proofThe answer is paired with visual explanations and original CGWB fact-sheet pages.

TRUST BY DESIGN

Useful enough to act on. Honest enough to question.

Protected evidence

Groundwater searches, weather, calculations, and source sheets require a verified account.

Private generation

Google sign-in protects model answers and account-owned chat history; disabling the LLM stops answer generation entirely.

No password collection

Google verifies identity. I.G.R.I.S. never receives or stores a Google password.

Clear limits

Assessment-unit and state data cannot guarantee one borewell’s yield, quality or legal approval.

BUILT TO GROW

Today’s prototype runs locally. Tomorrow’s intelligence can scale without changing the citizen experience.

The model gateway accepts any OpenAI-compatible local or hosted model. A stronger future model can add deeper multilingual reasoning and more capable tool use while the deterministic location, database, weather, evidence and security layers remain stable.
